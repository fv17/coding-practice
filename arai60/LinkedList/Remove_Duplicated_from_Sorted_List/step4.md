# 解法について
- 二重ループ
  - 重複を見つけた場合、仕事を引き継がず（次のループに渡さず）、連続して重複している箇所を全てスキップする
- 一重ループ
  - 重複を見つけた場合、仕事を引き継ぎ（次のループに渡し）、1つだけスキップして後は引き継ぎ先に任せる
# 不変条件
- 不変条件（英: invariant）とは、ある処理の間、常に真であることが保証される条件のこと。真のまま変わらないので不変
- ループにおける不変条件は、仕事の引き継ぎにおいて、何を約束・保証してループを回しているかを意識することが大事
