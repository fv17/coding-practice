# 解法を文章で表す
## 二重ループ
### 概要
- 今見ているノード node と同じ値を持つノードが後ろに連続していたら、その“連続部分”をまるごとスキップする
- 言い換えると、各ノードごとに、後ろに連続する同じ値のノードを内側ループで全部削ってから次に進む
### 詳細
1. リストを先頭から順に辿る
2. 各 node について、 node.next の値が node と同じである限り、node.next を次の次のノードへ飛ばすことで、重複ノードを削除
3. 同じ値の node が無くなったら、 node を1つ進めて、次のグループに移る
4. リストの末尾までこれを繰り返す

## 一重ループ
### 概要
- 「今のノード node とその次のノード node.next のペア」だけを見て、重複していたら次を飛ばす／そうでなければポインタを進める
### 詳細
1. リストを先頭から辿る
2. 今の node と次の node.next の値を比較
3. 同じ値なら、次のノード(node.next)を1つ先のノード(node.next.next)に付け替える。異なる値なら node を1つ先に進める
4. リストの末尾までこれを繰り返す
