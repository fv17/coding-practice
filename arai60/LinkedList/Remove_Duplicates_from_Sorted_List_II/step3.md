# 解法を文章で表す
## 重複が見つかったら仕事を引き継がず、該当する値は全てスキップするパターン
### アイデア
1. リストはソート済みなので、同じ値は必ず連続して現れる。
2. 「結果リスト」と「まだ判定していない部分」を分けて考え、
    - 重複していない値 → 結果リストの末尾につなぐ
    - 重複している値 → その値のノードをまとめて全部スキップする
3. 先頭が重複ブロックになるケース（例: 1 -> 1 -> 2 や 1 -> 1 -> 1）もあるので、ダミーノード（dummy）を先頭の一つ前に置いておき、ここから結果リストをつなぎ直す。

そのために、ポインタを2つ使う。
- tail: 結果リストの末尾
- current: 今調べている位置
